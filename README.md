A program that writes one one-line joke about working beside AI coding agents, for make.fun's "The joke about the demo" bounty. The joke: a coding agent fixes the demo crash the fastest way it knows how.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (UTF-8, one line, no network, deterministic — every run writes the same bytes).
